# Plan — Hewn Motion: a real video room, built to make good things, not scans

Saved 2026-11-09 02:52 MST · workspace `~/Development/hewn-video-studio/.hermes/plans/`
Deadline for the seven hackathon videos: **Nov 11, 15:00 MST**

## Goal

Build `~/Development/hewn-motion` — a HyperFrames-based production room where every
shot is an HTML composition, so an agent can author real motion design (product UI with
camera moves, kinetic type, sound) and a human can edit any shot and re-render only that
shot.

## Why this replaces what exists

The current rig renders terminal transcripts with PIL. Verified on the gameshelf draft
(`terms/hail`-style terminal): the frame at 3.0 s is a directory listing, `games: 0`, text
in the top-left 60%, the other 40% empty, no colour, no motion, no music. It is a scan of
a repo, not a demo of a product. No pacing or caption work rescues it.

The fix is not better automation of the same output; it is a different output medium.
HyperFrames takes HTML + CSS + GSAP and renders frames deterministically, which means:

- the **real product UI** can be composited as a still or video and moved with CSS
  transforms (crisp at 2× capture, no screen recording, so the Wayland black-window
  problem disappears);
- **type can be animated** (kinetic titles, lower thirds, counters) instead of appearing
  line by line in a fake terminal;
- **each beat is its own file**, so revising one shot costs seconds and cannot break the
  others.

**Assumptions**

- Render happens on this box, headless, from the project directory.
- GSAP is pinned locally (the docs load it from `cdn.jsdelivr.net`; a render must not
  depend on a CDN being up).
- Narration stays a separate file per beat (`_vo/<entry>/<entry>-NN.wav`) — reuse
  `vo_split.py`; the music bed is generated locally (Music Studio / ACE-Step is on this
  machine) so there is no licensing question.
- Product footage is captured as **stills and short clips via Playwright**, not by
  recording the desktop.

## Architecture

Three layers, each independently testable:

1. **Engine** — the `hyperframes` CLI inside `~/Development/hewn-motion/`. It renders a
   `film.html` that hosts one nested composition per beat.
2. **Authoring tools** — `tools/build_film.py` (film.json → film.html, pure Python,
   deterministic), `tools/capture_ui.py` (Playwright → 2× stills/clips of the real UI),
   `tools/audio.py` (VO + bed + ducking + hits → one mix), `tools/gate.py` (measures the
   rendered file and the compositions; returns `shippable` + failed checks).
3. **Surfaces** — the `motion` agent tool and a dashboard tab in a plugin
   (`~/.hermes/plugins/hewn-motion`), mirroring Music/Video Studio so all three feel like
   one product. Not built until the engine produces a film worth editing.

Sequencing rule: **one excellent 45-second film before a hundred features.** Tasks 1–8
produce the gameshelf film; only then batch the other six.

```html
      .fromTo("#root .ui", { scale: 1.06, x: 40, y: 24, opacity: 0 },
                         { scale: 1, x: 0, y: 0, opacity: 1, duration: 1.1, ease: "power2.out" }, 0.25)
      .to("#root .ui", { x: -26, y: -10, duration: 2.2, ease: "none" }, 1.4); /* slow push */
    window.__timelines["shot-hero"] = tl;
  </script>

```

Three rules that matter more than the styling:

1. **The first frame must already have a subject.** No fade-from-black as frame 0 — a
   judge sees a black rectangle and scrolls. Start at 80% opacity, finish in 300 ms.
2. **Every shot moves.** A still image with no transform is a slide, not a video. Küche
   rule: at least one continuous transform (push, pan, parallax) for the whole shot.
3. **Text minimum is `--t-body` (34 px at 1080p).** Anything smaller is unreadable on a
   phone, which is where these are watched.

**Accept:** the host file in Task 4 renders this shot and the words are legible at 1080p.

```python
#!/usr/bin/env python3
"""film.json -> film.html. One nested composition per beat, laid end to end.

Deterministic: the same film.json always produces the same film.html, so a diff means a
real change and a render is reproducible.
"""
import argparse
import json
import os

ACCENTS = {"blue": "shot--accent-blue", "amber": "shot--accent-amber",
           "cyan": "shot--accent-cyan", "violet": "shot--accent-violet",
           "green": "shot--accent-green", "red": "shot--accent-red"}

HEAD = """<!doctype html>
<html lang="en">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=%(w)d, height=%(h)d" />
    <link rel="stylesheet" href="styles/tokens.css" />
    <script src="vendor/gsap.min.js"></script>
    <style>body { margin: 0; background: #0b0d10; }</style>
  </head>
  <body>
    <div id="root" data-composition-id="main" data-start="0" data-duration="%(total).1f"
         data-width="%(w)d" data-height="%(h)d">
"""

HOST = """      <div id="host-%(id)s"
           data-composition-id="%(comp)s"
           data-composition-src="%(src)s"
           data-start="%(start).1f" data-duration="%(dur).1f"
           data-track-index="%(track)d"
           data-width="%(w)d" data-height="%(h)d"></div>
"""

TAIL = """    </div>
    <script>
      window.__timelines = window.__timelines || {};
      window.__timelines.main = gsap.timeline({ paused: true });
    </script>
  </body>
</html>
"""


def render(film: dict) -> str:
    w, h = film.get("width", 1920), film.get("height", 1080)
    beats = film["beats"]
    total = round(sum(float(b["duration"]) for b in beats), 3)
    out = [HEAD % {"w": w, "h": h, "total": total}]
    start = 0.0
    for i, b in enumerate(beats, start=1):
        comp = b.get("composition") or os.path.splitext(os.path.basename(b["src"]))[0]
        out.append(HOST % {"id": b["id"], "comp": comp, "src": b["src"],
                           "start": start, "dur": float(b["duration"]),
                           "track": i, "w": w, "h": h})
        start = round(start + float(b["duration"]), 3)
    out.append(TAIL)
    return "".join(out)


def main():
    ap = argparse.ArgumentParser()
    ap.add_argument("film_json")
    ap.add_argument("--out", required=True)
    a = ap.parse_args()
    film = json.load(open(a.film_json))
    html = render(film)
    os.makedirs(os.path.dirname(os.path.abspath(a.out)), exist_ok=True)
    with open(a.out, "w") as f:
        f.write(html)
    print(f"{a.out}  beats={len(film['beats'])}  "
          f"total={sum(float(b['duration']) for b in film['beats']):.1f}s")


if __name__ == "__main__":
    main()
```

```python
#!/usr/bin/env python3
"""Capture the real UI as crisp stills (and optional clips) for use as shot media.

2x device scale means a 960px panel photographed at 1920px and scaled in CSS still looks
sharp; that is what makes a product shot read as a product, not as a screenshot.
"""
import argparse
import os
from playwright.sync_api import sync_playwright


def capture(url, out_dir, name="ui", width=1600, height=1000, actions=None,
            scale=2, clips=None):
    os.makedirs(out_dir, exist_ok=True)
    shots = []
    with sync_playwright() as pw:
        browser = pw.chromium.launch(args=["--force-device-scale-factor=%d" % scale])
        page = browser.new_page(viewport={"width": width, "height": height},
                                device_scale_factor=scale)
        page.goto(url, wait_until="networkidle")
        page.wait_for_timeout(1200)
        for i, step in enumerate(actions or []):
            kind = step[0]
            if kind == "click":
                page.click(step[1])
            elif kind == "eval":
                page.evaluate(step[1])
            elif kind == "wait":
                page.wait_for_timeout(int(step[1]))
            page.wait_for_timeout(400)
            p = os.path.join(out_dir, f"{name}-{i + 1}.png")
            page.screenshot(path=p)
            shots.append(p)
        p = os.path.join(out_dir, f"{name}-final.png")
        page.screenshot(path=p)
        shots.append(p)
        browser.close()
    return shots


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("url")
    ap.add_argument("--out", required=True)
    ap.add_argument("--name", default="ui")
    a = ap.parse_args()
    for s in capture(a.url, a.out, a.name):
        print(s)
```

**Implement** — `~/Development/hewn-motion/tools/audio.py`:

```python
#!/usr/bin/env python3
"""VO + bed + ducking + hits -> one mix at -16 LUFS.

Ducking is a sidechain compressor keyed on the voice, so the bed drops only while someone
is speaking. Hits are short fades on the bed at each cut, which is what makes an edit feel
deliberate rather than stitched.
"""
import argparse
import json
import os
import subprocess

last_graph = ""


def _run(args):
    subprocess.run(args, check=True, capture_output=True)


def mix(vo, bed, total, out, cuts=(), bed_gain=0.0, vo_gain=0.0, sample_rate=48000):
    """vo: [(path, start_seconds), ...]; total: film length in seconds."""
    global last_graph
    inputs, filters, labels = [], [], []
    for i, (path, start) in enumerate(vo):
        ms = int(start * 1000)
        inputs += ["-i", path]
        filters.append(f"[{i}:a]adelay={ms}|{ms},volume={vo_gain}dB[v{i}]")
        labels.append(f"[v{i}]")
    inputs += ["-i", bed]
    bed_idx = len(vo)
    filters.append(f"[{bed_idx}:a]volume={bed_gain}dB,atrim=0:{total},asetpts=N/SR/TB[bedin]")

    # a short dip in the bed at every cut: the ear reads it as an edit landing
    expr = "1"
    for c in sorted((c for c in cuts if c > 0.2), reverse=True):
        expr = f"if(between(t,{c - 0.06:.3f},{c + 0.12:.3f}),0.62,{expr})"
    filters.append(f"[bedin]volume='{expr}':eval=frame[bed]")

    filters.append("[bed][vsum]sidechaincompress=threshold=0.05:ratio=8:attack=8:"
                   "release=280[ducked]")
    filters.append("".join(labels) + f"amix=inputs={len(vo)}:normalize=0[vsum]")
    graph = ";".join(filters) + ";[ducked][vsum]amix=inputs=2:normalize=0[mix]"
    last_graph = graph
    tmp = out + ".pre.wav"
    _run(["ffmpeg", "-y", "-v", "error", *inputs, "-filter_complex", graph,
          "-map", "[mix]", "-ar", str(sample_rate), "-ac", "2", tmp])
    _loudnorm(tmp, out)
    if os.path.exists(tmp):
        os.remove(tmp)
    return out


def _loudnorm(src, dst, target=-16.0):
    probe = subprocess.run(
        ["ffmpeg", "-hide_banner", "-i", src, "-af",
         f"loudnorm=I={target}:TP=-1.5:LRA=11:print_format=json", "-f", "null", "-"],
        capture_output=True, text=True).stderr
    start = probe.rfind("{")
    stats = json.loads(probe[start:probe.rfind("}") + 1])
    _run(["ffmpeg", "-y", "-v", "error", "-i", src, "-af",
          f"loudnorm=I={target}:TP=-1.5:LRA=11:"
          f"measured_I={stats['input_i']}:measured_TP={stats['input_tp']}:"
          f"measured_LRA={stats['input_lra']}:measured_thresh={stats['input_thresh']}:"
          f"offset={stats['target_offset']}:linear=true",
          "-ar", "48000", "-ac", "2", dst])


if __name__ == "__main__":
    ap = argparse.ArgumentParser()
    ap.add_argument("--vo", action="append", default=[], help="path@start_seconds")
    ap.add_argument("--bed", required=True)
    ap.add_argument("--total", type=float, required=True)
    ap.add_argument("--cut", action="append", type=float, default=[])
    ap.add_argument("--out", required=True)
    a = ap.parse_args()
    vo = [(p.rsplit("@", 1)[0], float(p.rsplit("@", 1)[1])) for p in a.vo]
    mix(vo, a.bed, a.total, a.out, a.cut)
    print(f"{a.out}  {a.total:.1f}s  cuts={len(a.cut)}")
```

## Task 7 — the gate that says whether it is actually good (TDD)

Existing `gate` checks measured duration and loudness. The failures that made the last cut
unwatchable were none of those. `tools/gate.py` adds three:

| Check | Rule | Why |
|---|---|---|
| `hook` | mean luma of frame 0 ≥ 12 **and** frame 0 differs from frame 15 by ≥ 0.5% of pixels | a black or static first frame is why people scroll |
| `motion` | in every 1-second window, ≥ 1.0% of pixels differ from the previous frame | catches "slide deck with narration" |
| `legibility` | smallest declared `font-size` in any `compositions/*.html` ≥ 26 px | 18 px type is invisible on a phone |

```python
#!/usr/bin/env python3
"""Measure a film. Returns pass/fail per check plus one verdict.

Every threshold here exists because a specific bad video shipped without it.
"""
import glob
import os
import re
import subprocess


def _frames(path, seconds, fps=30, size="160x90"):
    """Downscaled raw RGB frames, cheap enough to diff in Python."""
    raw = subprocess.run(
        ["ffmpeg", "-v", "error", "-i", path, "-t", str(seconds), "-vf",
         f"fps={fps},scale={size}", "-pix_fmt", "rgb24", "-f", "rawvideo", "-"],
        capture_output=True).stdout
    w, h = (int(x) for x in size.split("x"))
    n = w * h * 3
    return [raw[i:i + n] for i in range(0, len(raw) - n + 1, n)], n


def _diff_ratio(a, b):
    if not a or not b:
        return 0.0
    changed = sum(1 for x, y in zip(a, b) if abs(x - y) > 12)
    return changed / len(a)


def check_hook(path):
    frames, _ = _frames(path, 1.0)
    if len(frames) < 2:
        return {"check": "hook", "pass": False, "detail": "no frames decoded"}
    first = frames[0]
    luma = sum(first) / len(first)
    move = _diff_ratio(frames[0], frames[min(15, len(frames) - 1)])
    ok = luma >= 12 and move >= 0.005
    return {"check": "hook", "pass": ok,
            "detail": f"luma {luma:.1f}, first-half-second change {move * 100:.2f}%"}


def check_motion(path, fps=30):
    frames, _ = _frames(path, 600, fps=fps)
    if len(frames) < fps * 2:
        return {"check": "motion", "pass": False, "detail": "film shorter than 2s"}
    worst, worst_at = 1.0, 0.0
    for sec in range(len(frames) // fps):
        base = sec * fps
        energy = sum(_diff_ratio(frames[base + i], frames[base + i + 1])
                     for i in range(fps - 1)) / (fps - 1)
        if energy < worst:
            worst, worst_at = energy, float(sec)
    ok = worst >= 0.010
    return {"check": "motion", "pass": ok,
            "detail": f"weakest second {worst * 100:.2f}% change at {worst_at:.0f}s"}


def check_legibility(film_dir):
    smallest, where = 999, ""
    for f in glob.glob(os.path.join(film_dir, "compositions", "*.html")):
        for m in re.finditer(r"font-size:\s*([0-9.]+)px", open(f).read()):
            v = float(m.group(1))
            if v < smallest:
                smallest, where = v, os.path.basename(f)
    ok = smallest >= 26
    return {"check": "legibility", "pass": ok,
            "detail": f"smallest type {smallest:g}px ({where or 'none found'})"}


def verdict(checks):
    failed = [c for c in checks if not c["pass"]]
    return {"shippable": not failed, "failed": [c["check"] for c in failed],
            "checks": checks}
```

## Risks, tradeoffs, open questions

1. **Render cost is unmeasured.** Task 1 measures it before anything else. If a 1920×1080
   HyperFrames render is slower than 4× realtime, the iteration loop that makes video good
   disappears — cut to 1280×720 previews for review, final 1080p at the end.
2. **Version churn.** HyperFrames is at `0.9.x` and shipping daily. Pin `0.9.26` in
   `package.json` and never `npx hyperframes@latest` mid-project; a silent contract change
   would invalidate every shot.
3. **GSAP from a CDN** is what the docs show. Vendored in Task 4 deliberately: a render that
   needs the internet is a render that fails at the worst moment.
4. **Fonts.** `Inter` may not be installed; `tokens.css` falls back to DejaVu Sans, which is
   legible but generic. Check `fc-list | grep -i inter` and, if absent, drop the variable
   font into `film/assets/fonts/` with an `@font-face` — one file, one line.
5. **Music.** The generated pad is licence-clean and cheap; it is also plainly synthetic.
   A real bed from Music Studio is better and is already on this machine — but generating it
   costs GPU time that the deadline does not have. Pad now, swap later; the mix step is one
   command either way.
6. **This does not fix copy.** A beautiful shot of a weak sentence is still a weak video.
   The narration stays the hardest part, and it is the one thing that should come from a
   human or from a reviewed draft — not from the template.
7. **Scope vs deadline.** Task 1–8 is the deliverable that matters (one film that is
   genuinely good, plus the engine to repeat it). Tasks 6–7 can be partially deferred: ship
   the hook and motion checks first, legibility second. Task 10 must not start before
   Nov 11.
8. **Open question:** does HyperFrames' renderer handle nested compositions that reference
   `../assets/...` paths relative to the composition file, or only relative to the project
   root? Task 3's template assumes the former. Verify in Task 3 by rendering the two-shot
   smoke film; if images 404, move `assets/` under `film/` and use `./assets/...`.
