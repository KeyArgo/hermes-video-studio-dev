## 1. The one-paragraph state

**Video Studio is installed, appears in the desktop sidebar, and opens its own studio app**
(a film rail, a stage player, a storyboard strip, a gate inspector). Underneath it are two
renderers: **HyperFrames** makes each shot (HTML → mp4, ~1.3× realtime) and **MLT/`melt`**
makes the cut (timeline XML → mp4, 45 s in 32 s). Projects interchange through
**OpenTimelineIO**. Two films exist and are shippable by the gate — Game Center and Aura —
but **the owner judged them "AI slop" and they have not been redesigned since**, which is
the open work that matters.

## 5. What is actually broken or missing

1. **Video quality.** The owner's verdict on both films: "AI slop, horrible… I can do better
   with ChatGPT." Root cause, established: the shots were hand-written CSS from one brief,
   skipping HyperFrames' documented method — no LOOK line from a brand, no story options, no
   SPEC with numbers, **none of the ~450 registry blocks**, no brand capture, no sound design
   on visible actions, no snapshot review. The registry search alone returned **101 blocks**
   for "product app showcase", **86** transitions, **71** grain/texture overlays.
2. **No remote.** Nothing is pushed, so `hermes plugins install <url>` cannot work elsewhere.
3. **The agent tool** (`video_studio`) still speaks only cutting-room vocabulary — no films
   ops, no timeline ops.
4. **No timeline yet.** Order is fixed by `films/<id>.json`; no dragging, trimming, undo.
5. **`films_api.MOTION`** is resolved at import; set `VIDEO_STUDIO_MOTION` before the host
   starts if you want a different workspace.
6. **Two shots exist as individual mp4s** (`renders/shots/shot-aura-{hero,any}.mp4`); the
   other beats have none, so an MLT render of Aura is picture for 17 s and black for 28 s.

## 6. The four install failures (do not repeat)

Each one looked like "the plugin is broken" and each was a different layer:

1. **Security scan.** `VERIFY.md` piped `curl` into `python3`; the validator flags
   `curl_pipe_python` as dangerous and the plugin would not load. Docs must use Python
   `urllib` or a file, never a pipe into an interpreter.
2. **No desktop pane.** The web dashboard tab (`dashboard/dist/index.js`) is *not* what the
   desktop app renders. Visibility needs `desktop/plugin.js` (ESM, imports limited to
   `@hermes/plugin-sdk`, `react`, `react/jsx-runtime`) registering `ROUTES_AREA` +
   `SIDEBAR_NAV_AREA`.
3. **`.hermes-package.json` means "inert".** That marker says "opt-in, wait for allowlist" —
   the plugin loads switched off with no visible row. A standalone pane must have **no**
   marker. The Electron reconcile can recreate it for packages under `plugins/<pkg>/desktop`.
4. **`ctx.rest` is not the plugin's own API.** It produced a 404 for `/films`. The pattern
   that works (and that Music Studio uses): a loopback host + `studio-host.json` + an iframe.
   `ctx.rest('/studio/host')` is the authoritative way to ask where that host is.
