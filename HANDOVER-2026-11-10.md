## 1. One paragraph

Video Studio is a Hermes plugin (loopback host + its own studio app) with six rooms: **Films,
Assets, Script, Timeline, Generate** — and one engine per job: **HyperFrames** renders typed
shots, **ComfyUI on sparke** renders generative ones (MiniMax H3 is live and produced a real
5.2 s clip today), and **MLT/`melt`** renders a timeline. The script room turns an idea into
timed beats; the shot generator turns beats into compositions; the timeline can seed itself
from a film and render an edit. The end-to-end loop runs: **idea → beats → shots → render →
gate**, and today it produced a 24.0 s film that **passes all three gate checks** (`shippable: true`,
weakest second 4.48 % motion, −16.1 LUFS) and is shipped as
`/mnt/AllShare/dev/videos/hackathon-2026-11-11/aura-sound-made-visible-24s.mp4`.

## 5. The three new subsystems

### 5.1 Generation (ComfyUI)

- `video_studio/comfy.py` — client: `status()`, `submit()`, `wait()`, `download()`, `render()`.
  Parameters are substituted **by node `_meta.title`**, never by node id.
- `video_studio/comfy_api.py` — `GET /comfy/status`, `GET /comfy/models`,
  `POST /comfy/render {workflow, params, out}`. Host comes from `comfy.json` in the workspace,
  default `http://10.0.0.52:8188`.
- `~/Development/hewn-motion/workflows/h3-minimal.api.json` — **the working H3 graph** in API
  format (15 nodes): UNETLoader(H3 fp8) → CLIPLoader(qwen3vl 32b, type `minimax`) → 2× VAELoader
  (video/audio) → MiniMaxH3SigmaShift → MiniMaxH3ImageToVideo(width,height,length) → BasicGuider
  → KSamplerSelect(res_multistep) + BasicScheduler + RandomNoise → SamplerCustomAdvanced →
  VAEDecode + VAEDecodeAudio → CreateVideo(fps 24, audio) → SaveVideo.
- Cost reference: **768×448, 124 frames, 20 steps ≈ 192 s** on a GB10. 1344×768 (default) will
  be slower; measure before promising anything.
- The 135-node UI workflow on the box (`data/user/MiniMax_H3_CE_v0.2.json`) is **not** API format
  and has rgthree switches/subgraphs. Do not try to run it directly.

### 5.2 Script room

- `video_studio/script.py` — `draft()` (lane → JSON), `parse()` (validation), `to_film()`,
  `save()`. Rules: target ±6 % (min 1.5 s), 2–24 beats, ≥2 s per beat, ≤22 words per line, a
  spoken line required, no invented metrics in the brief.
- `video_studio/shotgen.py` — `write_shot()` (lane → one composition), `check()` (static
  contract), `write_all()`. Honours `beat["src"]`; strips prose/fences around `<template>`.
- Routes: `POST /script/draft`, `/script/check`, `/script/save`,
  `/script/{film}/shots`, `/script/{film}/build` (author + render).

### 5.3 Timeline

- `video_studio/ops.py` — pure operations over JSON state; `_pure()` guarantees no caller state
  is mutated; `normalize()` prevents overlaps and recomputes total; history stack for exact undo.
- `video_studio/timeline_api.py` — `GET /timeline/{film}`, `POST .../ops`, `.../undo`,
  `.../reset`, `.../from-film`, `.../render`, `GET .../video`.
- UI `studio/timeline.js` — lanes V1/V2/A1/A2, drag to move, edge-drag to trim, sync-from-film,
  undo, render. It follows the film selected in the left rail (`window.__studioFilm`).

## 7. How a film is made now (the loop that works)

```bash
# 1. idea -> beats (lane)
POST /api/script/draft {"idea": "...", "seconds": 24, "shots": 4}
# 2. write films/<id>.json + .script.json
POST /api/script/save  {"title": ..., "beats": [...], "seconds": 24}
# 3. author compositions (one lane call per beat, ~10-20 s each)
POST /api/script/<id>/shots {"only_missing": true}
# 4. render (HyperFrames CLI, 24 s ≈ 35-55 s)
cd ~/Development/hewn-motion/film && npx --yes hyperframes@0.9.26 render --quality draft \
   --output ../renders/<id>-raw.mp4
# 5. sound: a bed exists at renders/bed-24.wav; mux + normalise
ffmpeg -y -i ../renders/<id>-raw.mp4 -i ../renders/bed-24.wav -c:v copy -c:a aac \
   -shortest -filter:a "loudnorm=I=-16:TP=-1.5:LRA=11" ../renders/<id>-final.mp4
# 6. gate
POST /api/films/<id>/gate
```

## 8. Known defects (read before promising anything)

1. **FIXED — the last-second motion.** Root cause was not design: generated shots place their
   "persistent motion" tweens **without a position argument**, so GSAP appends them *after* the
   existing chain (a 6 s scene would animate from 1.7 s to 7.7 s, or never at all), and two of
   the four files had no `// Ensure frame 0` anchor so earlier repairs silently did nothing.
   What actually fixed it: a **whole-frame slow zoom** — `tl.fromTo("#root", {scale:1},
   {scale:1.035, duration: <scene seconds>, ease:"none"}, 0)` — injected into every shot.
   Profile went from `[.. 10:0.08 17:0.12 ..]` to **every second ≥ 4.96 %**. The generic tool is
   `tools/fix_motion.py` + `tools/fix_sweep.py`; the pattern belongs in `shotgen.CONTRACT`:
   *motion tweens must carry an explicit time position*. 
2. **`hyperframes check` blocks rendering** when there are warnings (contrast, first_frame_empty,
   film_silent). Render with `--quality ...` still proceeds if lint is not `--strict`; the gate
   is the authority. Fix contrast by lightening accent text (`#6da2f8` passes on `#0b0d10`).
3. **Audio is a manual mux.** The film pipeline has no bed; `renders/bed-24.wav` was generated
   ad hoc (two sines + pink noise, lowpass, fades). Move this into `tools/audio.py`.
4. **H3 output is 768×448**, not 1080p. Frames must be upscaled (or generated at 1344×768) before
   they can sit beside typed shots in a 1080p film.
5. **Shot naming and prose wrappers were bugs** (produced `shot-shot-*.html`, and files starting
   with "Here's a composition…"). Both fixed in `shotgen.py`; four files were repaired by hand
   today. Re-running `write_all` on an existing film will skip them (`only_missing`).
6. **Timeline and Films keep separate state.** `from-film` seeds V1 once; editing the timeline
   afterwards does not write back to `films/<id>.json` (by design for now — decide which is
   authoritative before changing it).
7. **Render jobs can die silently** if launched as a detached shell job. Run HyperFrames in the
   foreground with a generous timeout, or via the plugin's `/films/{id}/render` job endpoint.
